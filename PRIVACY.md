# Privacy Policy — Supernova

Supernova is a Garmin Connect IQ data field. It runs entirely on your Edge device.

## What it collects

**Nothing.** Supernova reads only the sensor data your Edge device exposes to data fields (power, heart rate, speed, cadence, altitude, distance, etc.) and renders it on the screen. It does not store, transmit, log, or otherwise persist any of this data.

## What it stores

Only the four settings you set in the Connect IQ companion app, stored locally on the device:

- FTP (watts)
- Max HR (bpm)
- LTHR (bpm)
- Weight (kg)

These never leave the device.

## What it transmits

**Nothing.** Supernova makes no network requests. It has no internet permission. It does not communicate with any server.

## Permissions

- `UserProfile` — read-only, used solely to read body weight as a fallback when the user has not configured it in app settings. The value never leaves the device.
